* min-max scaling
* percentile normalization
* z score standardisation
* histogram equalization
* contrast limited adaptive histogram equalization
* whitestripe 
* kernel density estimation normalization
* possibility fuzzy c mean normalization
* bias corrected possibility fuzzy c mean normalization
